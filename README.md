# Habit Lab
Habit Lab es una aplicación web sencilla para poder registrar, visualizar, filtar, completar y eliminar hábitos personales.

El objetivo principal de este proyecto es que los alumnos practiquen y ejecuten lo aprendido en clase durante el módulo **JavaScript desde Cero** de **Dev.f**, impartido por **Daniel Gloria Florencio**.

Este proyecto está diseñado como una práctica integradora para reforzar conceptos fundamentales de JavaScript, manipulación del DOM y uso de un framework CSS.

## Referencia del módulo

El contenido base del módulo puede consultarse en el siguiente Notion:

[3. JavaScript desde Cero](https://ripple-mule-798.notion.site/3-JavaScript-desde-Cero-143742521a628090864eef8147733436)

## Objetivo del proyecto

El objetivo de Habit Lab es que los alumnos apliquen de forma práctica los conocimientos adquiridos en clase, especialmente:

- JavaScript básico
- Estructuras de control
- Funciones
- Arreglos
- Objetos
- Manipulación del DOM
- Eventos
- Almacenamiento en `localStorage`
- Uso de un framework CSS
- Tailwind CSS
- Buenas prácticas básicas de organización de código
  
## Tecnologías utilizadas

- HTML5
- JavaScript
- Tailwind CSS
- DOM API
- LocalStorage
